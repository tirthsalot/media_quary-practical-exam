# 🏃‍♂️ RunX – Online Shoes Store Website

RunX is a **fully responsive online shoes store website** created using **pure HTML and CSS**. The project focuses on clean UI design, responsiveness using media queries, and a modern e‑commerce layout for men, women, and kids shoes.

## 🌐 Live Project Overview

This website includes:

* Modern navigation bar
* Product listing sections
* About & category sections
* Children wear section
* Fully responsive footer with social icons
* Multi‑device responsive design

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling & layout
* **Font Awesome** – Icons
* **Media Queries** – Responsive design

---

## 📱 Responsive Breakpoints

The website is optimized for all screen sizes using the following breakpoints:

* **1400px** – Large screens
* **1200px** – Desktop
* **992px** – Laptop / Tablet landscape
* **768px** – Tablet
* **576px** – Mobile
* **400px** – Small mobile devices
